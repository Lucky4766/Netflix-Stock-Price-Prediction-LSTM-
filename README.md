## Overview
This project implements a deep learning-based time-series forecasting system using LSTM to predict Netflix stock prices from historical data.

## Description
Developed an end-to-end machine learning pipeline including data preprocessing, feature engineering, model training, and evaluation using Python. The system leverages LSTM networks to capture temporal dependencies in stock data and improve prediction accuracy.

The project includes automated workflows for data processing and model retraining, reducing manual effort and enabling continuous improvement. The application is containerized using Docker to ensure reproducibility across environments.

Designed with deployment in mind, the architecture is AWS-ready and follows scalable ML system design principles.

## Tech Stack
Python, TensorFlow/Keras, Pandas, NumPy, Docker, Git

## Key Highlights
- Time-series forecasting using LSTM
- Automated ML pipeline
- Docker-based deployment
- CI/CD-style retraining workflow
